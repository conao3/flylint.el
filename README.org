A lightweight linting framework for Emacs.

* Overview

Flylint provides a foundation for on-the-fly syntax checking in Emacs. It aims to offer a simple and extensible interface for integrating various linting tools.

* Requirements

- Emacs 24.4 or later

* Installation

** Manual Installation

Clone the repository and add it to your load path:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/flylint.el")
(require 'flylint)
#+end_src

** Using leaf.el

#+begin_src emacs-lisp
(leaf flylint
  :load-path "/path/to/flylint.el")
#+end_src

* Usage

Once installed, require the package in your Emacs configuration:

#+begin_src emacs-lisp
(require 'flylint)
#+end_src

* Customization

You can customize flylint through the customization interface:

#+begin_src
M-x customize-group RET flylint RET
#+end_src
